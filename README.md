# Library Full Stack KHAE - Presenter

## ErrorHandling-Demo branch

For the **Error Handling and User Feedback** classroom demonstration, use only:

`error-handling-demo/`

That demo is intentionally **stub-only** and does not use the repository's regular database-backed application.

- Frontend: `error-handling-demo/frontend`
- Stub backend: `error-handling-demo/backend`
- Demo instructions and paired presenter URLs: `error-handling-demo/README.md`

The other root-level application folders are part of the presenter/master repository baseline and are **not required for this error-handling demonstration**.
